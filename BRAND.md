# the Ridge

Preferred name: **the Ridge**. Brand line: **Garhwal x Japan**. Location: **Tungnath Valley**.

The identity pairs a Japanese-inspired open brush-style circle with Himalayan peaks, a terracotta sunrise/sunset disc, and valley contours. A vermilion seal beside the wordmark depicts the Japanese character yama (mountain). The mountain character is drawn as vector paths so it does not depend on Japanese font availability. The wordmark remains the Ridge.

Palette: forest green #1c4035, warm ivory #f5efe3, terracotta sun #c96643, vermilion seal #a34530.

Assets: `assets/the-ridge-logo.svg`, `the-ridge-logo-light.svg`, `the-ridge-mark.svg`. Wordmark lettering uses Georgia; outline the lettering in a design application for fixed production-print letterforms.
